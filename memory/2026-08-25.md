# 2026-08-25 — Task A: bootstrap

Built the whole scaffold for The Understudy. **No book content**, per §13
step 6 of the brief.

## Decisions taken before writing code

- **Aesthetic direction: "two surfaces."** The site's commentary is recessed
  below the page; the worked runs are raised above it. Typeface carries the
  same rule redundantly — serif = the book, sans = the site, mono = the
  machinery. Chosen because the polarity survives dark-mode inversion
  unchanged. Recorded in `about.html` as §12 requires.
- **Self-hosted typography.** Literata (body), Public Sans (site voice),
  JetBrains Mono (machinery) — 4 variable woff2, ~173KB, fetched once from
  jsDelivr at authoring time and committed with their OFL texts. Vendoring is
  not a runtime CDN dependency; the `<link>` would have been.
- **Testing:** `tools/check.py`, standard library only. Reconciles the global
  "always set up tests" rule with the brief's no-build-step constraint — a
  checker never runs at serve time.
- **`PROMPT.md` is a prompt log**, since `CLAUDE.md` is already the brief.

## Built

- Full tree with `.nojekyll`; `books/` empty.
- `assets/style.css`, ~1,480 lines: reset → tokens → typography → layout →
  components → print. Palette authored in OKLCH, committed as hex, every
  pair verified ≥ 4.5:1 on all three grounds in both themes.
- Three part templates (claim / mechanism / terrain) + `part.html` entry point
  + `book-index.html` + `meta.json`. They double as the CSS proving ground;
  their filler prose describes what belongs in each slot, so no book content
  leaked in.
- `index.html` (complete but bookless shelf, with a commented exemplar card),
  `about.html` (five tests, honest limit, design direction).
- `README.md`, `ARCHITECTURE.md`, `LICENSE` (MIT, digster), `.gitignore`,
  `PROMPT.md`, `LEARNINGS.md`, `.claude/launch.json`.

## Deviations from the brief's stated layout

1. **Three part templates instead of one.** One file with all three variants
   would need three `<h1>`s (forbidden) or every section heading demoted a
   level (which would stop the real CSS selectors being exercised).
2. **`PROMPT.md` is a log, not a copy of the brief.**

Both documented in README.

## Bugs found and fixed during verification

- Trace arithmetic in the mechanism template: `(0x0092 << 12)` written as a
  16-bit shift. Caught by executing it. Correct result `0x0009_2A3C`.
- `.val { white-space: nowrap }` pushed the page body 50px wide at 360px.
- Two bugs *in the checker*, found by a negative test: a substring match that
  accepted prose as a joint map, then a regex anchoring error that failed
  every page.
- `unicode-range` on only the Literata roman; removed.
- Headings without `id`s (13 of them); the rule is now enforced as a failure.

## Verified

Checker green (9 checks, 0 failures) and its negative test confirms all nine
fire. Browser pass: zero external network requests, dark mode with polarity
preserved, 360px with no sideways scroll, skip link first in tab order with a
visible focus ring, footnote `:target` round-trip, print rules re-encoding the
two surfaces as borders.
